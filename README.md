# AI-Assisted Job Market Tracker

## 📌 Project Overview
The AI-Assisted Job Market Tracker is a Power BI dashboard that analyses job postings, skill demand, salary information, and hiring trends to help understand the job market.

## 🎯 Project Objectives
- Analyse total job postings.
- Identify companies with the most job openings.
- Explore job demand by city and experience level.
- Compare average minimum and maximum salaries.
- Identify frequently required skills.
- Analyse job postings by employment type.

## 🛠️ Tools Used
- Microsoft Power BI
- GitHub

## 📊 Dashboard Features
- Total Job Postings KPI
- Average Minimum Salary
- Average Maximum Salary
- Companies Hiring
- Jobs by Experience Level
- Top 10 Companies Hiring
- Job Postings by Employment Type
- Job Postings by City
- Average Salary by Experience Level
- Job Postings by Required Skills
- Interactive filters for city, experience level, and employment type
